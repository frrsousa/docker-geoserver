# GeoServer Lite (para Render)

Versão leve do GeoServer para executar em ambientes com memória limitada (512 MB).

## Como usar no Render
1. Crie um novo Web Service.
2. Escolha **Public Git Repository** e insira o link deste repositório.
3. Confirme as definições:
   - **Runtime:** Docker
   - **Port:** 8080
   - **RAM:** 512 MB
4. Espere que a build termine (leva ~2–3 min).
